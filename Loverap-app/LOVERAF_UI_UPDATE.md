# Loveraf UI Update v1.2

This source package includes the requested marketplace UI revision.

## Updated screens

- **Home:** a shorter search bar, thin auto-sliding demo banners and two-row Top Categories. The single For You, Men, Women, Kids and Baby filter becomes sticky and changes the visible product set—there is no duplicate scrolling header.
- **Product details:** cart and report actions in the top bar; share and wishlist actions beside the metadata; smaller title; rating beside price; discount and savings summary; size selection; user reviews; and a thinner Store, Chat, Add to Cart, Buy Now footer. Both purchase buttons open a size, named-color and quantity selector first.
- **Address book:** the large Add New Address action opens a separate route for name, phone, division, dependent district and full-address fields. Saved addresses can be edited, removed or selected for delivery.
- **Store:** seller identity, rating, followers, Follow control, shipping performance, banner, all products, categories and chat navigation.
- **Navigation:** header and Android hardware Back actions now return through the local page stack.

All interactions remain local demo state. Backend persistence, remote images, authentication and live seller data should be connected in the API phase.

> The included APK files are the previously supplied builds. Rebuild the app from this updated source to produce a matching Android APK.
