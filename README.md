# Loveraf Server

This repository contains only the Loveraf Express, MongoDB/Mongoose and Socket.IO API in `server/`.

Environment files, credentials, dependencies, build output and backups are intentionally excluded from version control. Use `server/.env.example` as the configuration contract.

The production API deployment target is `https://api.loveraf.com/api/v1`. Deployment instructions are in `server/deploy/DEPLOYMENT.md`.
